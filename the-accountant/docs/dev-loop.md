# 账房先生 · 开发循环规约 v0.2（第八节补强）

> 配合《设计宪章 v1.0》《开发 Rubric v1.0》《游戏设计底稿 v0.3》使用。
> 效力顺序：**宪章 > rubric > 底稿 > 本规约**。本规约只定义"怎么跑评审循环"，不新增验收标准。

---

## 一、循环总览

```
主开发(Fable) 出剧本/代码
      ↓
 模拟玩家(全新上下文) 冷启动试玩 → 出《评审报告》(rubric 打分)
      ↓
 判定: 总分≥48/54 且 无红线为0 ? ──是→ Accept, 进入下一单元
      │否
      ↓
 主开发按"需要修改①②③"回修 ──→ 重新 spawn 全新模拟玩家复测
      ↓(同一问题 3 轮未解)
 升级 Bin 人工裁决
```

铁律三条：
1. **冷启动**：每一轮（含回修复测）都 spawn **全新上下文**的模拟玩家，禁止复用上轮记忆——否则它"记得上次的坑"，金融小白视角失效，C4 情绪曲线与 B2 承担后果就评不准了。
2. **试玩，不审码**：只从玩家视角走流程（点按钮、读公文、做选择、看账本变化）。允许读 rubric（标尺），**禁止读源码、禁止被告知本章要命名的那个偏差**（防预判，否则装不出真实踩坑）。
3. **作者不自评**：出剧本/代码的上下文，永不兼任模拟玩家。

## 二、模拟玩家 · 输入

| 输入 | 内容 | 说明 |
|---|---|---|
| 试玩物 | 当前可运行的序章/章节（HTML/CSS） | 跑得起来才送测 |
| 宪章 + rubric | 全文 | 打分依据 |
| 立场卡 | 见下 | 强制代入 |

**立场卡（必须代入）**：
> 你第一次玩，不懂股票，也没什么投资框架。你按"常识"和书里的格言做决定，会贪那口浮盈、会想加仓、会觉得便宜就该买。你不知道任何金融术语。你只凭体感：哪里期待、哪里犹豫、哪里紧张、哪里被耍、哪里看不懂还被卡住。玩完后问自己——我记住了什么？我理解了关于"人"的什么，而不只是关于"股票"的什么？

## 三、红线检查（一票否决：任一为 0 → 直接 Reject，其余不必算）

逐项答 是/否 + 一句证据（直接取自 rubric 红线 + 底稿三道锁的体感落地）：

**rubric 红线**
- [ ] 是否违背设计宪章？
- [ ] 是否破坏金融真实性？（市场之内出现不真实行情/案例/公文）
- [ ] 是否让 NPC 直接讲答案？（含术语泄进台词）
- [ ] 是否把季九章写崩？（现代化 / 弱智化 / 工具人化）
- [ ] 是否出现随机剧情杀？（失败不可解释、或非玩家决策导致）
- [ ] 是否以金融知识替代游戏体验？

**底稿三道锁 → 体感落地（红线级，破了就不是这个游戏）**
- [ ] 穿越是否被解释/返场/出现时间线把戏？
- [ ] 运行时是否出现任何生成式/不可复现内容？
- [ ] 体感锁是否生效？（跌停日"卖出"可点 = 破；T+1 日卖出入口未灰 = 破）
- [ ] 苏州码子是否始终配阿拉伯数字、无需玩家解码？

## 四、Rubric 逐条打分（每项 0~3，满分 54，≥48 进主线）

### A. 核心理念（/18）
| 项 | 判分 | 证据/复现 |
|---|---|---|
| A1 符合设计宪章（红线项） | /3 | |
| A2 仍围绕"人生中的账"（**不是股票/金融故事，是人生故事**） | /3 | |
| A3 尊重市场真实性（不为剧情改市场） | /3 | |
| A4 尊重季九章人设（不现代化/弱智化/工具人化） | /3 | |
| A5 体现古今文明碰撞（非一方教育另一方） | /3 | |
| A6 让玩家主动思考（非作者给答案） | /3 | |

### B. 游戏循环（/18）
| 项 | 判分 | 证据/复现 |
|---|---|---|
| B1 完整决策循环（观察→判断→行动→结果→复盘） | /3 | |
| B2 玩家真正承担后果（无读档式教学/无剧情保护） | /3 | |
| B3 明确反馈（知道为何成功/失败） | /3 | |
| B4 避免随机惩罚（失败必须可解释） | /3 | |
| B5 形成下一次决策动力（玩家想继续） | /3 | |
| B6 节奏控制（**单章 3~5 分钟**，记实测秒数） | /3 | |

### C. 表达质量（/18）
| 项 | 判分 | 证据/复现 |
|---|---|---|
| C1 没有说教（无"所以我们应该…"） | /3 | |
| C2 没有信息堆砌（每章只讲一个认知） | /3 | |
| C3 通过体验完成表达（非对白解释） | /3 | |
| C4 情绪曲线（期待→犹豫→紧张→结果→理解） | /3 | |
| C5 留下悬念（自然想进下一章） | /3 | |
| C6 长期记忆点（记住一句话/一个决定/一个错误/一个人物） | /3 | |

> **宪章映射提醒**（评分时对照，不另计分）：
> - 宪章第八条「情绪先于知识」≈ C4：体验顺序必须 **先紧张/后悔/犹豫，最后才理解**。
> - 宪章第三条「亏损不是失败，认知没长才是失败」≈ B2+C6：一次亏损若给了新理解，算成功一局。
> - 宪章第六条「玩家永远拥有选择」≈ A6+B4：**不能只有唯一正确答案**。

### ★ 双层暗线收束规则（统辖每章复盘，违反 = A6/第八条不合格）
- **章级·微认知**：每章末可由考卷命名**一个**偏差（机械标签，制造"这就是我刚干的事"）。允许。
- **游戏级·大主题**（如"市场只是人生的一本账""主角始终是局外接盘者"）：**全程禁止明示**，只许靠反复的体感与"未命名的不安"累积，**到终章自然收束，且最好由玩家自己说出，而非游戏说出**。
- **每章复盘天花板**：只到"季九章感到哪里不对劲、却说不出"。**禁止替他把那层意思总结成话。**
- **模拟玩家附加检查（红线邻接）**：本屏/本章复盘是否**提前替玩家点破了游戏级大主题**？若"作者把话说完了"→ 计入 A6 与第八条扣分，重则按"违背宪章"红线处理。

### ★ 季九章嗓音铁律（A4 人设）
- 钱谷师爷，三十年自负懂规矩。**全局禁止自怨自艾 / 卖惨 / 受害者姿态 / 自我贬低。**
- 他的痛靠**观察的精确与克制的陈述**渗出，不靠倾诉。账平不了，他冷冷陈述一个事实，不哀叹。
- 删除信号：叹气式省略号（"可账……平不了"）、"我只是个…"、"是我自己的"这类自怜框架、感叹号堆砌。
- **模拟玩家检查**：复盘/独白是否出现自怜、卖惨、受害者口吻、或自我贬低？出现 = A4 扣分（人设崩），并列入"需要修改"。

## 五、评审报告输出格式（rubric 强制 + 本规约补充）

**【rubric 强制部分】**
```
总分：
  核心理念：__/18
  游戏循环：__/18
  表达质量：__/18
  总计：__/54
需要修改：① ② ③
最终建议：□ Accept  □ Revise  □ Reject
```

**【本规约补充：让回修可执行】**
- 红线检查结果（任一为 0 必须置顶列出）
- 实测试玩时长（秒）+ 试玩路径（选了哪些选项）
- "需要修改"每条附：**严重度（红线/重大/次要）+ 复现步骤 + 命中的 rubric 条号**

---

## 六、判定与回修

- **Accept**：总分 ≥48 且无红线为 0；遗留"次要"项进 backlog。
- **Revise**：未达 48，或有"重大"未达标 → 回修"需要修改"列表，重新冷启动复测。
- **Reject**：任一红线为 0 → 直接退回。
- **终止**：同一问题回修满 3 轮未解 → 停止自动循环，升级 Bin 人工裁决（防无限循环 / 防 agent 互相迁就磨低标准）。
- **防漂移**：每轮复测用**全新**模拟玩家 + **同一份**未改 rubric；rubric/宪章只有 Bin 能改。

## 七、当前阶段（序章+第一章竖切）精简
- 独立 agent 只保留"模拟玩家"一个；
- 史实·引文核查、行为金融·教学核查，本阶段作主开发提交前的**串行自检清单**，不单独起 agent；
- 内容扩到多章、检查彼此独立且重复时，再升级为常驻并行 agent。
