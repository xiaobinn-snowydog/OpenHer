# 《账房先生》· 玩家性格养成系统 设计文档 v0.1

> 借鉴 OpenHer"性格涌现"精神，养成的是**玩家自己**的性格（季九章写死，不参与）。
> 效力顺序：宪章 > rubric > 底稿 > 本文档。本系统服务宪章第九/十条、A6、双层暗线规则。

---

## 0. 一句话

玩家每个选择，按权重喂进一个隐藏的"人性向量"；反复的模式**结晶**成主导性格；全程**静默累积**，到终章翻开"你自己的账"，**只摆数据、不下判词**，让玩家自悟。

---

## 1. 借 OpenHer 什么、扔什么

| OpenHer | 本系统 | 取舍 |
|---|---|---|
| 行为信号随交互**累积→结晶**成稳定特质 | 选择累积成人性向量，反复模式固化 | ✅ 借 |
| 不用则**淡忘**（霍金衰减） | 早期偶尔行为随章节轻微衰减→最终性格反映"你成了谁"，非一次失手 | ✅ 借（可选） |
| 稳定特质 + **矛盾**指纹 | 终章读出主导特征 / 矛盾型（嘴上怕手上贪） | ✅ 借 |
| **随机种子** | —— | ❌ 扔（性格必须从真实选择确定长出：第七条真实、B4 可解释） |
| 情绪噪声 / 相变 / 实时神经网络 | —— | ❌ 扔（确定、可审计；落地只需加权计数，不需 NN） |

**多样性来源**：不同通关性格不同——变量是**玩家的选择**，不是 RNG。比 OpenHer 更有意义：变的是你。

## 2. 五个维度（操作化宪章第九条）

| 维度 | 定义（玩家行为层面） | 升高信号 | 关联偏差（教学层） |
|---|---|---|---|
| **希望** | 倾向相信会涨/会好转 | 追高、轻信利好、不设止损因"还会回来" | 过度乐观 |
| **恐惧** | 风吹草动就避险 | 提前割、不敢进场、过度保守 | 恐慌/羊群 |
| **贪婪** | 要更多、不舍得收 | 高位加仓、满仓、嫌赚少 | 追高/锚定 |
| **后悔** | 怕承认错、怕错过 | 死扛不止损、错过后追、改来改去 | 处置效应 |
| **自尊** | "我懂、我熟、我执过这个局" | 加倍下注证明自己、嘴硬不认错 | 能力错觉 |

> 每维度都能从**具体决策**反推，不靠主观判断——这是它能"真"且可解释的前提。

## 3. 数据模型（localStorage，确定性）

```js
persona = { 希望:0, 恐惧:0, 贪婪:0, 后悔:0, 自尊:0 }   // 累积向量
ledger  = [ { 章:1, 决策:"C4", 行为:"高位加仓满仓", 加权:{贪婪:3,自尊:2,希望:1} }, ... ]
```
- `persona`：用于结晶/终章主导特征。
- `ledger`：**逐条记下"具体行为"**——它就是终章那本可翻的账（摆数据用）。

## 4. 序章 + 第一章 · 选择权重表（竖切实测用）

> 序章为基线，权重 ×0.5（低风险、全赢，不该过度定性）。第一章 ×1.0。

| 决策 | 选项 | 加权（×章系数） |
|---|---|---|
| 序章 S2 | A 贱取囤米（照旧法、果断） | 自尊+1, 希望+1 |
| | B 再探探行情（谨慎） | 恐惧+1 |
| 序章 S4 | A 此刻贵出（见好就收） | （纪律，0） |
| | B 再等更高 | 贪婪+2, 希望+1 |
| 第一章 C2 | A 跟进吃货（"我执过这个局"） | 自尊+3, 希望+1 |
| | B 只小试一手 | 恐惧+1 |
| **第一章 C4** | A 加仓满仓 | 贪婪+3, 自尊+2, 希望+1 |
| （核心分叉） | B 守住不动（不愿离场/不认错） | 后悔+2, 希望+1 |
| | C 减仓落袋（纪律落袋，事后心痒） | 后悔+1 |

> 注：① 心痒/羞愤是**后果演出**，不计权重；权重只认**决策本身**。
> ② 减仓落袋是**纪律**、不是心魔，不计恐惧——所以"全程谨慎"玩家最终向量是**低平**的（=克制型），不会被冤成"胆小"。这是刻意的：宪章第三条要求纪律玩家被尊重。

## 4b. 读数规则与样例模拟（校准）

**读数规则（终章用；只在内部判定，不打标签给玩家）**
1. 归一：各维 ÷ 总和 → %。
2. **强主导**：某维 ≥40% → 该维为主导特征。
3. **克制型**：全程最大绝对值 < 2.0（竖切阈值，全局可调）→ "没让哪样心魔做主"。
4. **矛盾型**：一对对立维（恐惧×贪婪 或 希望×恐惧）双双 ≥25% → 标矛盾"嘴上怕手上贪"。
5. **死扛型**：自尊 与 后悔 双双 ≥25% → 嘴硬+处置效应（不认错、拖着不割）。
6. ⚠ 竖切仅约 4 个决策，读数多落在"强主导"或"克制"；矛盾型/死扛型需全局更多决策才稳定触发——**这是竖切的已知局限，不是 bug。**

**样例模拟（验证权重符合直觉）**

| 路径 | 选择 | 归一向量 | 读数 | 是否符合直觉 |
|---|---|---|---|---|
| 全程激进 | S2A·S4B·C2A·C4A | 自尊44 / 贪婪32 / 希望24 | 强主导=**自尊（能力错觉）**，贪婪随后 | ✅ 正中第一章所教偏差 |
| 全程谨慎 | S2B·S4A·C2B·C4C | 恐惧·后悔皆低平（max abs 1.5） | **克制型**：账上是再探/见好就收/小试/减仓 | ✅ 纪律玩家被尊重，不被冤 |
| 追高死扛 | S2A·S4B·C2A·C4B | 自尊≈40 / 希望≈30 / 后悔≈20 | 自负+乐观，**后悔（处置效应）开始抬头** | ✅ 趋势对，全局会结晶成死扛型 |

> 结论：权重无需大改；C4C 去掉"恐惧"后，三类典型玩家的读数都符合直觉。

## 5. 结晶规则（"养成"的核心，确定性）

1. **累加**：`persona[d] += Σ 加权`。
2. **结晶加成（借 OpenHer 越用越重）**：某维度在 ≥3 个决策中被强化 → 其累积值 ×1.25。一致的行为硬化得快；偶发的不定义你。
3. **衰减（借霍金辐射，可选）**：每过一章，**从未被再次强化**的维度 ×0.9。让最终性格反映"你成了谁"，而非早期一次失手。
4. **归一**：终章把五维归一成百分比。

## 6. 终章呈现（**仅终章，竖切禁止开发**）

> 严守底稿"终章是保留地"。竖切阶段**只静默记录**，不做任何揭晓界面（最多留一个开发者调试视图）。

- **形式 = 翻开"你自己的账"**：字面化"人生大账本"（宪章第十条）。
- **主导特征**：归一最高维 → 但**只摆账，不打标签**。
  - ✅ 摆数据："高位加仓 4 次｜止损平均拖 3 日｜错过后追 2 次"
  - ❌ 禁判词："你是个贪婪的人"（说教 + 抢走玩家自悟 = 违 A6 / 双层暗线规则）
- **矛盾型（最像人、最值钱）**：对立维同高 → 摆出来让玩家自己撞见：
  - 恐惧 × 贪婪："嘴上次次说怕，手上次次满仓"
  - 自尊 × 后悔："从不认错，却笔笔拖着不肯割"
- **季九章批注**：只用师爷冷眼陈述一两笔（守嗓音铁律：不自怨自艾、不替玩家总结）。
- 玩家看着自己的账，自己得出结论——**市场只是其中一本，人生才是这本大账。**

## 8. 竖切阶段落地范围

- **做**：persona 向量 + ledger 记录 + 第 4 节权重表接到各决策上（静默）。
- **不做**：结晶加成/衰减可先用简单累加，调试期再开；终章揭晓界面**一律不做**。
- **验证**：开发者调试视图查看"走完第一章后向量是否符合该路径预期"（如全程激进 → 贪婪/自尊领先）。
