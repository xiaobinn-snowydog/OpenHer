# 账房先生（The Accountant）

> 借清代绍兴师爷季九章穿越现代股市，用"被打疼、但不被羞辱"的亲历，
> 让玩家重新理解**风险、欲望、判断、成长**。
> **不是炒股游戏，是人生游戏——市场只是人生大账本里的一本。**
